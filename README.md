# 3D Personal Portfolio

A beautiful, responsive 3D personal portfolio website built with HTML, CSS, and JavaScript. Features interactive skills filtering, portfolio categorization, and modern 3D animations.

## 🚀 Features

### Interactive Skills Section
- **Dynamic Filtering**: Click on skill categories to filter content
  - "All Skills" - Shows all skills
  - "Graphic Designing" - Shows only graphic design skills
  - "UI/UX" - Shows only UI/UX design skills  
  - "Web Development" - Shows only web development skills
- **Animated Progress Bars**: Skill proficiency displayed with animated progress bars
- **3D Hover Effects**: Cards rotate and lift on hover for depth

### Portfolio Showcase
- **Category Filtering**: Filter portfolio items by type
  - Graphic Design projects
  - UI/UX Design projects
  - Web Development projects
- **Interactive Overlays**: Hover to reveal project details and links
- **3D Card Effects**: Portfolio items have perspective transforms

### Modern Design Elements
- **3D Floating Shapes**: Animated geometric shapes in hero section
- **Gradient Backgrounds**: Beautiful gradient color schemes
- **Glass Morphism**: Frosted glass effects with backdrop blur
- **Smooth Animations**: CSS transforms and transitions throughout
- **Parallax Effects**: Subtle parallax scrolling for depth

### Responsive Design
- **Mobile-First Approach**: Optimized for all screen sizes
- **Hamburger Menu**: Collapsible navigation for mobile devices
- **Flexible Grid Layouts**: Auto-adjusting grid systems
- **Touch-Friendly**: Optimized for touch interactions

### Additional Features
- **Smooth Scrolling**: Seamless navigation between sections
- **Intersection Observer**: Scroll-triggered animations
- **Contact Form**: Functional contact form with validation
- **Social Links**: Connect through various social platforms
- **Loading Animations**: Smooth page load transitions

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility
- **CSS3**: Advanced styling with:
  - CSS Grid & Flexbox
  - 3D Transforms
  - Animations & Transitions
  - Media Queries
  - Custom Properties
- **JavaScript**: Interactive functionality:
  - Event Listeners
  - DOM Manipulation
  - Intersection Observer API
  - Form Validation

## 🔧 Customization

### Changing Content
1. **Personal Information**: Update name, title, and description in `index.html`
2. **Skills**: Modify skill cards in the skills section
3. **Portfolio Items**: Add/remove portfolio projects
4. **Contact Details**: Update contact information and social links

### Styling Modifications
1. **Colors**: Modify CSS custom properties in `styles.css`
2. **Animations**: Adjust animation durations and effects
3. **Layout**: Customize grid layouts and spacing

### Adding New Categories
1. Add new filter button in HTML
2. Add corresponding `data-category` to items
3. Update JavaScript filtering logic if needed

## 🚀 Getting Started

1. **Clone or Download** the project files
2. **Open** `index.html` in a web browser
3. **Customize** content to match your profile
